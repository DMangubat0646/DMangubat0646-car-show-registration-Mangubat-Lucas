## How to run both apps

**Backend (C# / .NET 10)** – `cd backend`, then `dotnet run --project Api`. API: http://localhost:5205, Scalar docs: http://localhost:5205/scalar/v1

**Frontend (React + Vite)** – `cd frontend`, `npm install`, `npm run dev`. Dashboard: http://localhost:5173
See `frontend/README.md` for switching between sample data and the real API.
